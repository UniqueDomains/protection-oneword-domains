## 🧱 Field summary

- `domain` — Fully qualified domain name.
- `status` — Current acquisition state for the domain in the public extract.
- `purchase_price` — Visible purchase price when available.
- `renewal_price` — Visible renewal price when available.
- `attractiveness` — Composite naming score used as a decision-support signal.
- `demand` — Relative buyer-pressure score when available.
- `length` — Character count without the TLD.
- `registrar` — Registrar name when known.
- `created_at` — Creation timestamp when known.
- `expires_at` — Expiry timestamp when known.

## ⚠️ Methodology and caveats

This set is entirely made up of .protection domains. The names range from broad commercial terms such as business.protection to more specific or abstract words like sauna.protection, gracious.protection, and alabaster.protection. That makes the selection relevant to both buyers looking for clear keyword alignment and buyers looking for unusual but ownable brand positions. When comparing these domains, focus first on whether the word naturally fits a protection use case, then weigh memorability, spelling clarity, and asking price. With a median ask of $2,770, the strongest choices are usually the ones where the keyword, commercial intent, and extension work together cleanly.

- All domains in this selection use the .protection extension
- Median ask across the set is $2,770
- Broad keywords tend to read more commercially
- Check whether the word fits a real protection context
